# Security

Report a vulnerability privately through GitHub: open the [Security tab](https://github.com/polybjorn/strommekalkulator/security) of this repository and choose **Report a vulnerability**. Please do not open a public issue for it.

This is a static site with no backend, so the likely issues are in `index.html` and `app.js` (for example script injection through the URL hash) or in the data and workflow files. I read reports as time allows; there is no bounty.
